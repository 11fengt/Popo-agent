# Popo-agent 示例知识文档

Popo-agent 是一个用于个人文档问答的 AI Agent 工作台。

## 支持的知识文件

当前支持 UTF-8 编码的 TXT、Markdown 和 JSON 文本，不支持直接解析 PDF、Word 或图片。

## 数据如何保存

聊天历史保存在当前浏览器的 localStorage 中。知识文档和向量索引保存在 MCP 服务进程内存中；重启后端后，知识库需要重新上传。

## 问答流程

上传文档后，服务端会进行文本分块和向量化。Agent 可以调用 retrieve_knowledge 工具检索相关片段，并结合片段生成回答。界面会显示检索来源，便于对照原文。

## 适用场景

适合本地学习、个人资料问答和项目演示。当前版本没有用户登录、权限隔离或多人知识库，不适合未经改造直接作为公开多人服务。
