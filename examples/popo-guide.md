# Popo-agent 示例知识文档

Popo-agent 是一个用于个人文档问答的 AI Agent 工作台。

## 支持的知识文件

当前支持 UTF-8 TXT、Markdown、包含文本层的 PDF 和 Word `.docx`。不支持 JSON 上传、旧版 `.doc`、扫描 PDF 的 OCR 或图片知识文档。

## 数据如何保存

聊天历史保存在当前浏览器的 localStorage，不跨设备同步。文档切片、embedding 和来源元数据持久化到 ChromaDB。只要保留数据目录并连接相同集合，重启后端后可以恢复知识库，无需重新向量化已有文档。BM25 索引在 MCP 内存中，启动后从已有切片重建。

## 问答流程

上传文档后，后端按标题、段落和页码解析，再按估算 token 预算分块。提问时同时使用向量检索和 BM25 关键词检索，以 RRF 融合排名，默认返回前 4 个片段。Agent 通过 retrieve_knowledge MCP 工具取得片段，再结合内容生成流式回答并展示来源。

## 适用场景

适合本地学习、个人资料问答和项目演示。当前版本没有用户登录、权限隔离或多人知识库，不适合未经改造直接作为公开多人服务。
